# Personal Portfolio Website

This is a personal portfolio website project that showcases my work and skills. It is built using React and includes various components to create a responsive and visually appealing layout.

## Project Structure

The project is organized as follows:

```
personal-portfolio
├── src
│   ├── components
│   │   └── Header.jsx       # Navigation bar and logo component
│   ├── pages
│   │   └── Home.jsx         # Main landing page component
│   ├── styles
│   │   └── main.css         # CSS styles for the website
│   └── index.jsx            # Entry point of the application
├── public
│   └── index.html           # Main HTML file
├── package.json             # npm configuration file
└── README.md                # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd personal-portfolio
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm start
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to view the portfolio website.
